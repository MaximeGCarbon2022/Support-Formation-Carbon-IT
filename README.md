# 🎓 Support de Formations Carbon

Dépôt centralisé de formations techniques pour développeurs .NET, C#, et technologies web.

---

## 📚 Formations disponibles

### 🔍 [ReviewCode](Formations/ReviewCode/)

**Apprentissage par la code review**

Formation pratique axée sur l'analyse de code existant pour développer l'esprit critique et identifier les bugs, anti-patterns et problèmes d'architecture.

**Compétences** : Code review, debugging, architecture .NET, API REST, async/await, EF Core

**Public** : Développeurs juniors à confirmés

**Format** : Exercices pratiques avec code à analyser

---

### 💻 [.NET](Formations/.NET/)

**Fondamentaux et avancés .NET/C#**

Formation complète sur l'écosystème .NET et le langage C#.

**Compétences** : C# fondamentaux, POO, LINQ, async/await, ASP.NET Core, Entity Framework

**Public** : Débutants à intermédiaires

**Format** : Cours théoriques + exercices pratiques

---

### 🥋 [Kata](Formations/Kata/)

**Exercices de programmation**

Collection de katas (exercices de code) pour s'entraîner aux algorithmes et améliorer ses compétences en C#.

**Compétences** : Algorithmique, résolution de problèmes, TDD

**Public** : Tous niveaux

**Format** : Exercices courts et répétables

---

### ⚛️ [NextJS](Formations/NextJS/)

**Framework React pour le web**

Formation sur Next.js pour construire des applications web modernes et performantes.

**Compétences** : React, Next.js, SSR, SSG, routing, API routes

**Public** : Développeurs front-end/full-stack

**Format** : Cours + projets pratiques

---

### 🗄️ [SQL](Formations/SQL/)

**Bases de données relationnelles**

Formation sur SQL et la gestion de bases de données relationnelles.

**Compétences** : SQL, requêtes, jointures, optimisation, modélisation

**Public** : Développeurs back-end/full-stack

**Format** : Cours théoriques + exercices SQL

---

## 🚀 Démarrage rapide

### Cloner le dépôt

```bash
git clone <repository-url>
cd Support-Formation-Carbon-IT
```

### Naviguer vers une formation

```bash
cd Formations/ReviewCode
# ou
cd Formations/.NET
```

Chaque formation contient son propre README avec les instructions détaillées.

---

## 📋 Prérequis généraux

- **.NET SDK** : Version 6.0 ou supérieure
- **IDE** : Visual Studio, VS Code, ou Rider
- **Git** : Pour cloner et gérer les versions
- **Bases de C#** : Recommandé pour la plupart des formations

---

## 🤝 Contribution

Les contributions sont les bienvenues ! Pour ajouter ou améliorer une formation :

1. Fork le projet
2. Créer une branche (`git checkout -b feature/nouvelle-formation`)
3. Commit les changements (`git commit -m 'Ajout formation X'`)
4. Push vers la branche (`git push origin feature/nouvelle-formation`)
5. Ouvrir une Pull Request

---

## 📝 Structure d'une formation

Chaque formation suit une structure cohérente :

```
NomFormation/
├── README.md                 # Description et instructions
├── Exercises/               # Exercices pour les apprenants (optionnel)
├── Solutions/              # Corrections (optionnel)
└── Ressources/             # Supports de cours (optionnel)
```
