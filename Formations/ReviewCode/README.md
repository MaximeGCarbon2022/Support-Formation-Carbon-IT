# 🎯 Exercices de Code Review C#

## 📚 Progression suggérée

### Niveaux 1-3
**Focus :** Logique, performance
- **Niveau 1 - FizzBuzz** : Logique conditionnelle
- **Niveau 2 - MostFrequentNumber** : Optimisation algorithmique
- **Niveau 3 - ReverseString** : Gestion des types et performance

### Niveaux 4-5
**Focus :** Algorithmes et optimisations avancées
- **Niveau 4 - Anagrammes** : Validation et edge cases
- **Niveau 5 - TwoSum** : Structures de données optimales

### Niveau 6
**Focus :** Algorithmes complexes et refactoring
- **Niveau 6 - LongestSubstring** : Sliding window et clean code

### Niveau 7
**Focus :** Architecture .NET et API REST
- **Niveau 7 - LibraryAPI** : Code review d'une API complète (DI, async/await,HttpClient, EF Core, nommage, codes HTTP, sécurité)
