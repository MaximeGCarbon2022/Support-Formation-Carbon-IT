# 📝 Sujet – FizzBuzz

## 🎯 Objectif
Écrire un programme qui affiche les nombres de **1 à 100** selon les règles suivantes :

## 📋 Règles
- Si le nombre est divisible par **3** → afficher `Fizz`
- Si le nombre est divisible par **5** → afficher `Buzz`  
- Si le nombre est divisible par **3 ET 5** → afficher `FizzBuzz`
- **Sinon** → afficher le nombre lui-même

## ✅ Exemple de sortie attendue
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
16
...
```

## 🔧 Signature attendue (C#)
```csharp
public static void Run()
// ou alternative pour plus de flexibilité :
public static void Run(int max = 100)
```
